# Von ♡ Angel — First Monthsary Website

A pink romantic interactive monthsary website.

## How to use

1. Open `index.html` in your browser.
2. The special date is currently **07/17**.
3. Add your photos to the `images` folder:
   - `photo1.jpg`
   - `photo2.jpg`
   - `photo3.jpg`
   - `photo4.jpg`
4. Add your music file to the `music` folder and name it:
   - `maging-sino-ka-man.mp3`

## Customize

- Main text and love letter: `index.html`
- Colors, layout, animations: `style.css`
- Buttons/date logic: `script.js`

The website is responsive and works on phones and computers.
